# мойИПЦ — фронтенд приложения

## 1. Описание проекта

«мойИПЦ» — одностраничное веб-приложение (SPA) для просмотра категорий потребительских расходов. Интерфейс позволяет просматривать категории в формате ленты и плитки, знакомиться с описаниями, датами и весом категорий, а также ставить лайки и фильтровать список по дате.

В лабораторной работе № 5 данные категорий представлены моковыми объектами, которые хранятся в коде фронтенда. Для отображения списка категорий не используются запросы к базе данных или серверному API.

## 2. Структура приложения

Приложение содержит две страницы:

1. **Лента** — просмотр одной категории с описанием и дополнительной информацией.
2. **Моя корзина (плитка)** — просмотр карточек категорий и фильтрация по дате.

В нижней части интерфейса расположена навигационная панель с четырьмя пунктами: «Лента», «Добавить», «Моя корзина» и «Войти». В рамках лабораторной работы доступны переходы только между лентой и плиткой. Пункты «Добавить» и «Войти» отображаются как недоступные.

## 3. Страница «Лента»

Лента отображает одну категорию расходов. В качестве фона используется видео, связанное с текущей категорией.

### Отображаемые данные

- Название категории.
- Описание категории.
- Дата, за которую представлены данные.
- Вес категории в процентах.
- Количество лайков.

### Кнопки и элементы управления

| Элемент | Назначение |
|---|---|
| «Ещё» | Раскрывает полное описание категории. |
| «Скрыть» | Сворачивает раскрытое описание. |
| Кнопка с сердцем | Ставит или снимает лайк. При нажатии цвет сердечка меняется с белого на розовый. |
| Кнопка со стрелкой вниз | Переключает отображаемую категорию на следующую. |
| «Лента» в нижней панели | Открывает страницу ленты. |
| «Моя корзина» в нижней панели | Открывает страницу с карточками категорий. |

При выборе категории на странице плитки открывается лента с соответствующей категорией. Идентификатор категории передаётся через параметр URL `category`.

## 4. Страница «Моя корзина» (плитка)

Страница плитки отображает список категорий в виде карточек.

### Информация в карточке

- Изображение категории.
- Название категории.
- Дата публикации данных.
- Количество лайков.

### Поля и кнопки

| Элемент | Назначение |
|---|---|
| Поле выбора даты | Позволяет выбрать дату для фильтрации категорий. |
| Кнопка поиска | Применяет фильтр по выбранной дате. |
| Карточка категории | Открывает ленту с выбранной категорией. |
| «Лента» в нижней панели | Открывает страницу ленты. |
| «Моя корзина» в нижней панели | Открывает страницу плитки. |

Если дата не выбрана, отображаются все категории. После выбора даты и нажатия кнопки поиска остаются только категории, дата которых совпадает с выбранной.

Если подходящих категорий нет, отображается сообщение «На выбранную дату категорий нет».
